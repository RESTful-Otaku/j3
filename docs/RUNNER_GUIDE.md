# Tournament runner guide

This is the complete path from an empty venue to published medals. Use the hands-on guide in the app if you want each step checked for you: **Guides & progress → Runner**.

## Before you start

Have the event name, dates, venue, a logo or banner, a rough participant count and the names of your officials ready. You do not need to know federation rule numbers: J3 stores rules as reusable configuration.

## 1. Create the event

Open **Setup wizard** and work through the five steps:

1. **Event** — name, display title, venue, dates and theme.
2. **Disciplines** — one row per discipline, with match length, rounds, scoring and kit requirements.
3. **Categories** — age, weight, height, grade and gender ranges. Set a participant cap.
4. **People** — paste invitations as `email, phone, role, club`.
5. **Review** — fix any red issues, optionally save a template, then **Launch tournament**.

Launching creates the event snapshot, invites and officials, then auto-generates pools, brackets and assignments. See the [organiser guide](/docs/guide) for the plain-language version.

## 2. Check the draw

Open **Fight pools** and **Brackets**. Confirm that:

- pools are balanced and same-club fighters are spread;
- BYEs are allocated to seeds where your format policy says so;
- the third-place plan respects the "have they already met?" rule;
- every category has enough entrants to be valid.

Use **Regenerate balanced pools** if the seed produced a poor spread. Manual drag/shuffle is available on the bracket for moderators with the right authority.

## 3. Brief your team

Open **Event config** and share it with officials and competitors. It lists required kit, match times, course attendance, venue information and the public schedule. Open **Display control** to assign dashboard templates to screens.

## 4. Check-in and weigh-in

On **Check-in & import**, enter the official weight for each arrival. J3 flags anyone outside their declared class. Use **Add fighter** for late entries, and the CSV buttons to export start lists. Forfeits, no-shows and injuries are recorded from the same area so the draw can be rebalanced.

## 5. Run the mats

On each **Mat control** console:

1. select a contest;
2. start the authoritative clock;
3. pause when the referee stops the bout;
4. log holds, penalties and techniques from **Official console**;
5. confirm the result, which locks the bout and publishes it everywhere.

Every confirmation asks for approval and writes an audit entry with actor, role, time and before/after values. See [live scoring rules](/docs/scoring).

## 6. Publish and celebrate

Open **Public board** on spectator screens, **Brackets** on the main wall and **Medal ceremony** for podium callouts. Use the PA controls to flash the next competitors and speak their names. **Tables & rankings** shows live club points and medals.

## After the event

Use **Audit trail** to resolve disputes, **Data explorer** to query the allow-listed tables, and **Account admin** to remove or change access. Save the event as a template before the next tournament so categories, rules and branding are reused exactly.
