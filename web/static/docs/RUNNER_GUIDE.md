# Tournament runner guide

Runners own event setup and day-to-day overrides. Admins can do everything a runner can plus the
authority matrix.

## Before you start

Pick a template or clone last year's event. Confirm disciplines, rule snapshots, categories,
venue and branding; copy the event URL for each display screen.

## 1. Create the event

Use the five-step wizard: identity/branding → rules → categories → people → review. Validation jumps
to the offending step. Launch saves a reusable template and generates pools, brackets, assignments
and dashboard views.

## 2. Check the draw

Review balanced pools, same-club spread, BYEs and format fallback. Drag fighters or match order to
override; create awards and a medal table once categories are final.

## 3. Brief your team

Assign officials to mats/contests; unassigned corners cannot score. Share `/official` and mat console
URLs, the schedule and PA conventions.

## 4. Check-in and weigh-in

Search/check in fighters, record metric weight, and flag out-of-class competitors. Handle no-shows
and injuries with a recorded technical outcome that rebalances the pool.

## 5. Run the mats

Monitor `/control` and the public clock. Confirm results, manage promotion and third-place/bronze
rules, and trigger PA callouts. Undo or correct any score with an audit entry.

## 6. Publish and celebrate

Open `/public`, `/brackets`, `/tables` and `/medals` on displays. Use the guided ceremony, winner
animations and Street Fighter theme where appropriate.

## After the event

Review `/audit`, export CSV/brackets/scoresheets, archive the event and save the setup as a template
for next time.
